Introduction¶

Background Super Mario 64 is a still popular video game from 1996 for the Nintendo 64 gaming console. The game is split into different levels where a variety of objectives are completed to achieve stars. After collecting enough stars, the player unlocks more levels and eventually faces the last challange before the game ends. A subsect of players emerged who participate in a compitition to see how fast the game can be completed, thus "speedrunning". There are various different speedrunning categories, some including glitches or 'skips', allowing players to reach the end of the game earlier than if playing the game as intended.

The data being examined is from Speedrun.com, a website where users can submit their attempts, 'runs', for official ranking.

Due to the nature of the API, please allow ample time to run calls. Sometimes calling the API too frequently in a given time period causes timeouts. Please rerun the cells or maybe wait and restart the kernel and try again, thanks.

def get_runs_by_year(category_id, game_id='o1y9wo6q', start_year=2022):
    run_dates = []
    
    # Need to page through pages to get information
    offset = 0
    limit = 200
    stop_fetching = False

    while not stop_fetching:
        
        # Filter to game and category, verified runs, sorted by newest date
        url = (
            f"https://www.speedrun.com/api/v1/runs"
            f"?game={game_id}&category={category_id}&status=verified"
            f"&max={limit}&offset={offset}&orderby=date&direction=desc"
        )
        
        # Sometimes hit API query hit limits
        try:
            resp = requests.get(url)
            if resp.status_code == 400:
                print(f"⚠️  400 Error at offset {offset}. Skipping...")
                break
            resp.raise_for_status()
        except Exception as e:
            print(f"❌ Request failed: {e}")
            break
        
        # Retrieve dates
        data = resp.json()
        runs = data.get('data', [])
        if not runs:
            break
        for run in runs:
            date = run.get('date')
            if not date:
                continue
                
            # Sometimes hit invalid dates
            try:
                year = int(date[:4])
            except ValueError:
                continue
            
            if year >= start_year:
                run_dates.append(date)
            else:
                stop_fetching = True
                break
        offset += limit
        time.sleep(1)
        
    # Dataframe with count of runs grouped by year of date
    df = pd.DataFrame(run_dates, columns=['date'])
    df['year'] = pd.to_datetime(df['date']).dt.year
    return df.groupby('year').size().reset_index(name='runs')

def get_world_records(category_id, game_id='o1y9wo6q'):
    
    # Filter to game and speedrun category, and the top 100 records
    url = f"https://www.speedrun.com/api/v1/leaderboards/{game_id}/category/{category_id}?top=100"
    runs = requests.get(url).json()

    # Retrieve data of interest
    run_list = []  
    for r in runs['data']['runs']:
        player = r['run']['players'][0]
        player_id = player.get('id', 'guest')
        run_list.append({
            'time_seconds': r['run']['times']['primary_t'],
            'player_id': player.get('id', 'guest'), 
            'player_name': requests.get(f"https://www.speedrun.com/api/v1/users/{player_id}").json()['data']['names']['international'],
            'date': r['run']['date']
        })
        
    # Store in dataframe
    df = pd.DataFrame(run_list)
    return df

The natural next interesting topic would be to look at routing and 'splits'. The routes are the order of which players collect stars and common practice in speedrunning is to time each segement (time to star 1, time to star 2, etc.). Often times there are especially tricky sections in a speedrun that when failed constitutes an immediate 'reset': a player quits the run before finishing. An analysis of where most runs failed, which tricks result in the most time saved, or how to optimize routes could be a huge benefit to the speedrunners. The website splits.io used to be many players go to archive for this information, which has unfortunaly shut down early 2025 and so collecting this data is now more arduous.
